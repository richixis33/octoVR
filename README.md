# octoVR

A lightweight VR/3D project starter for exploring immersive experiences in the browser and beyond.

## Overview

This repository is a starting point for building virtual reality experiences, interactive 3D scenes, and prototype tooling around the octoVR idea.

## Features

- Simple project structure
- Easy to extend for VR and 3D interactions
- Ready for experiments and prototypes
- Suitable as a base for further feature development

## Getting started

1. Clone the repository
2. Install dependencies
3. Run the project locally
4. Start experimenting with the scene and interaction logic

## Development

Use your preferred tooling for the app stack you add here, and keep the project organized as it grows.
